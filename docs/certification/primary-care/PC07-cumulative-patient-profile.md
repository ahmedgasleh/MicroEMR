## Security cross-check

Existing components use API permissions (`Patients.View`, `ClinicalData.Manage`) and tenant/patient-scoped procedures. Several Web proxy controllers expose only `[Authorize]`, relying on downstream API authorization; runtime direct-route denial is required. Missing CPP categories/customization/printing have no enforcement to assess.
