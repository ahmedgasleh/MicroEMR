## Security cross-check

Existing components use API permissions (`Patients.View`, `ClinicalData.Manage`) and tenant/patient-scoped procedures. The new clinical-history Web and API controllers both explicitly enforce those effective permissions; runtime direct-route denial remains required. Missing CPP categories/customization/printing have no enforcement to assess.
