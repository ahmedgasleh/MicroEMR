## Security and history cross-check

API list/detail uses `Referrals.View`; create/transitions/link/unlink use `Referrals.Manage`. The Web referral proxy is authenticated but downstream API provides the principal permission boundary. SQL validates patient/referral/document relationships; unlink deletes only the linkage, not the patient document, and writes audit. The workflow records current state and timestamps, but a user-visible referral history and immutable letter snapshot were not identified.
