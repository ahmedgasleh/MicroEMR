## Security cross-check

Patient reads/writes are protected at Web and API layers by `Patients.View` and `Patients.Edit`; API mutations also require centralized clinical actor resolution. Repository procedures require tenant-database routing but are not a separate business-permission boundary. No merge/roster/enrolment/contact authorization exists because those capabilities were not found.
