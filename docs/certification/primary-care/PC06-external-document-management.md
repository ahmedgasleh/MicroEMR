## Lifecycle and security cross-check

Files store original filename, storage key, MIME type, size, extension, SHA-256, description, category/type, title, source organization, author/provider, document/received dates, status, upload/update actor and timestamps. `PatientFile_Archive`/`Restore` use row-version concurrency and `AuditLog`; content is not deleted. Web and API endpoints explicitly enforce effective `Documents.View`/`Documents.Manage`, while UI mutation actions follow `Documents.Manage`; runtime denial still requires evidence. Referral linkage continues to target `PatientDocument`, not `PatientFile`.
