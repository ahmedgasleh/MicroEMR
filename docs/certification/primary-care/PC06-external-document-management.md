## Lifecycle and security cross-check

Files store original filename, storage key, MIME type, size, extension, SHA-256, description, category, status, upload/update actor and timestamps. `PatientFile_Archive`/`Restore` use row-version concurrency and `AuditLog`; content is not deleted. The Web files controller has `[Authorize]`, while API enforcement provides `Documents.View`/`Documents.Manage`; direct-Web denial and UI action visibility require verification. Referral linkage currently targets `PatientDocument`, not `PatientFile`.
