## Security and audit cross-check

The scheduler Web controller requires `Scheduling.View`; API reads require `Scheduling.View` and mutations `Scheduling.Manage`. Central actor resolution applies to writes. Stored procedures enforce resource/blocked-time conflicts, status rules and row-version concurrency, and write both `AuditLog` and `AppointmentHistory` for identified mutations. UI hiding is not relied upon; manual tests must exercise direct Web/API denial. Month View is analyzed only and remains unchanged.
