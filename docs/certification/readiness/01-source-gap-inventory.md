# Certification Source-Gap Inventory

## Target release and process

Target: Ontario Primary Care `PCON-2024-02`.

Tracked Stage 3 release: CDS-S 5.1, Data Migration 5.1, Hosting 1.3, Privacy & Security 2.1, Primary Care Baseline 5.5 and CDM 4.4. Newer 5.2 DFU foundation material is future-readiness material, not a substitute.

The certification sequence tracked for planning is Stage 1 Application Submission; Stage 2 Application Assessment; Stage 3 Foundation and Functional Validation; Stage 4 EHR Connectivity and Tools Validation; Stage 5 Reference Site Assessment. Detailed preparation/validation material may be supplied after successful Stage 2 readiness assessment and is not assumed to be public.

## Material classification

- Exact certification specifications available locally: none confirmed as complete packages.
- Detailed clauses unavailable: CDS-S 5.1, Data Migration 5.1, Hosting 1.3, Privacy & Security 2.1, CDM 4.4, PC03 and PC04.
- Wording available but validation interpretation missing: parts of PC01 and PC06–PC10, especially PC08 and PC10.
- Future-only: newer DFU versions and specialty specifications.
