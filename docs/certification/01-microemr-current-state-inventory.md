# MicroEMR current-state capability inventory

## Classification

- **IMPLEMENTED**: concrete repository evidence exists for the described capability.
- **PARTIAL**: some capability exists, with important pieces visibly absent.
- **NOT FOUND**: repository-wide searches did not locate an implementation.
- **NEEDS VERIFICATION**: evidence exists, but behavior or operational configuration cannot be established from source alone.

These classifications describe only the stated capability, not OntarioMD conformance.

## Repository-wide limitations

Source inspection cannot prove production configuration, effective TLS/certificates, availability, backup/recovery, monitoring response, vendor policies, privacy assessments, training, support levels, or that each implemented flow meets every specification statement. Those items belong in the verification backlog and later requirement-level traceability matrix.
